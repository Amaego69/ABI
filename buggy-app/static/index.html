buggy-app

Демо-магазин с тремя намеренными багами. Нажми кнопку — если всё ещё сломано, увидишь ошибку; после фикса от Bug Investigator ответ станет успешным.

1. Checkout пустой корзины

Ожидаемо: IndexError — обращение к items[0] без проверки.

2. Скидка на цену-строку

Ожидаемо: TypeError — арифметика со строкой "99.99".

3. Async цена без await

Ожидаемо: ошибка с coroutine — забытый await.

Полный traceback смотри в логах контейнера / терминала uvicorn — его копируй в Bug Investigator. API docs: /docs
